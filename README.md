# Laboration 3, Angular
Denna webbplats är skapad i kursen Programmering i Typescript vid Mittuniversitetet. Syftet med webbplatsen är lära sig grunderna i ramverket Angular. 

Webbplatsen innehåller fyra sidor skapade som komponenter. Komponenterna koms åt genom routing med Angulars routingmetod "routerLink". Sidorna innehåller även komponenter header, som rymmer sidans rubrik och huvudmeny.

Under "Omvandling" finns ett verktyg för omvandling av olika enheter. Denna omvandlare är skapad i Typescript med hjälp av klassen "Converter" samt olika funktioner för att beräkna omvandlingarna. 

Webbplatsen finns tillgänglig vid:
https://angularsitelabb3.netlify.app/
